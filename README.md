# Welcome to Shenzhen · 深圳城市指南

## 这是什么

一份给参会代表和访客的实用手册：吃什么、住哪里、怎么走、看什么，以及会议周要注意什么。内容中英对照，点右上角 **EN / 中文** 即可切换。

本站为独立整理的信息指南，**非官方发布**。重要安排请以政府与 APEC 官方公告为准。
